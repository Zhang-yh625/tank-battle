# 坦克大战 Tank Battle

一个纯 **HTML + Canvas** 实现的经典坦克大战（Battle City）网页游戏，零依赖、无需构建，双击 `index.html` 即可游玩。

## 特性

- 🎮 经典玩法：驾驶坦克保卫基地，消灭所有敌军
- 🎯 4 种敌军：普通 / 快速 / 火力 / 装甲（4 点生命）
- 🧱 5 种地形：砖墙（可摧毁）、钢墙（不可摧毁）、河流、草丛、基地
- ⭐ 道具系统：★ 火力升级、◉ 护盾、✹ 清屏炸弹、+1 生命
- 🗺️ 3 个关卡，全部通关后胜利
- 🎵 简单音效、爆炸特效、屏幕震动
- 📱 支持触屏虚拟按键（手机 / 平板）

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| P | 暂停 / 继续 |
| R | 重新开始 |

## 本地运行

直接用浏览器打开 `index.html` 即可。

或者本地起一个静态服务器：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 在线试玩

在仓库 **Settings → Pages** 中启用 GitHub Pages（Source 选择 `main` 分支根目录），即可获得在线地址。
